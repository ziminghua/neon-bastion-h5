# 霓虹堡垒 H5 · 第一关

《霓虹堡垒》是一款纯前端、横屏、赛博朋克题材的 H5 塔防游戏。当前仓库保存第一关的可玩视觉基线，目标不是只做一个展示 Demo，而是验证一套可以低成本迭代、快速分发并逐步商业化的轻量游戏模型。

## 项目定位

核心方向是：

> 用高完成度的第一关吸引玩家，用短局塔防循环验证留存，再以激励广告为主要收入，逐步扩展关卡、成长系统和付费内容。

项目优先面向浏览器、H5 游戏平台和可承载 Web 游戏的流量入口。纯前端结构便于快速部署、换皮、测试素材和接入不同平台 SDK，也能避免早期投入过重的客户端研发成本。

## 核心玩法

- 横屏赛博朋克塔防战场
- 四种差异化炮塔：轨道、寒冰、等离子、奥术
- 建造、移动、交换、合成、升级和出售
- 10 波敌人、阶段性 Boss 和战术强化选择
- 单局时间较短，适合碎片化游玩和广告变现
- 后续可扩展关卡、炮塔、敌人、装备、任务和长期成长系统

## 一开始讨论的变现思路

### 1. 先用激励广告完成收入闭环

早期不依赖强付费，主要通过玩家主动选择观看的激励广告变现。广告必须对应明确、即时且有价值的游戏收益，避免强行打断战斗。

优先设计的激励点：

- 战败后复活一次或恢复部分核心装甲
- 结算时将金币、经验或材料奖励翻倍
- 开局获得一次随机强化或额外初始能源
- 免费刷新战术强化三选一
- 临时试用高级炮塔或特殊技能
- 补充体力、挑战次数或关卡门票

原则是“广告帮助玩家继续玩或更快成长”，而不是把正常体验拆碎后再收费恢复。

### 2. 插屏广告只放在自然断点

插屏广告作为补充收入，不作为核心体验。

合适位置包括：

- 一局完整结算后
- 返回关卡选择页面时
- 连续完成若干局后

不在战斗中途、建造操作中或 Boss 战前强制弹出。需要设置频控，并允许新玩家在前几局获得无插屏体验。

### 3. 付费放在验证留存之后

只有当关卡完成率、次日留存和重复游玩达到可接受水平后，再增加内购。早期付费以低压力、非强制项目为主：

- 去广告
- 新手礼包
- 月卡或每日补给
- 主题皮肤、炮塔外观和特效
- 永久解锁的便利功能
- 赛季通行证

尽量避免直接出售压倒性数值。付费主要提供外观、节省时间和更稳定的成长体验。

### 4. 用关卡和成长系统提高广告库存

单个关卡只能验证玩法，长期收入依赖玩家重复回来。后续需要逐步建立：

- 多章节关卡地图
- 炮塔解锁、升级与科技树
- 每日任务和七日目标
- 每日挑战、无尽模式和 Boss 挑战
- 随机战术组合与 Roguelite 局内构筑
- 活动关卡和周期性赛季内容

这些系统的目的不是单纯增加复杂度，而是提高留存、日均局数和玩家主动触发激励广告的机会。

## 推荐商业化优先级

### 第一阶段：验证玩法

目标是确认玩家是否愿意完成第一关、是否理解建造和合成，以及是否愿意再次挑战。

此阶段重点：

- 优化首局引导
- 控制单局时长
- 调整难度曲线
- 记录开始、失败、复活、胜利和退出行为
- 暂不堆叠复杂付费系统

### 第二阶段：接入广告

在稳定版本中加入平台广告 SDK，优先上线：

1. 失败复活广告
2. 结算奖励翻倍广告
3. 战术强化刷新广告
4. 低频结算插屏

### 第三阶段：建立长期成长

增加关卡选择、局外升级、任务和每日奖励，让玩家有持续目标，并根据数据决定是否加入去广告、礼包和外观付费。

### 第四阶段：投放与规模化

当留存和广告价值稳定后，再测试买量。素材重点突出：

- 炮塔合成升级
- 大量敌人被范围攻击清除
- Boss 压迫感
- 战败复活后的逆转
- 不同战术组合产生的明显差异

先用小预算测试点击率、安装或进入成本、首局完成率和广告回收周期，不在留存尚未验证时扩大投放。

## 关键数据指标

后续接入统计时，至少需要记录：

- 游戏加载成功率
- 首局开始率
- 教学完成率
- 第一关完成率
- 平均单局时长
- 失败波次分布
- 次日、七日留存
- 日均游戏局数
- 激励广告展示率和完成率
- 每名活跃用户广告收入
- 付费转化率和平均付费金额
- 投放用户的回收周期

广告展示次数不是唯一目标。若广告增加导致留存下降，最终总收入往往会更差，因此应同时观察用户价值和体验指标。

## 变现设计原则

- 先证明游戏好玩，再增加商业化强度
- 激励广告优先，强制插屏克制
- 广告只放在自然断点
- 新玩家前几局减少广告干扰
- 奖励必须清晰，观看前告知具体收益
- 保留无广告或低广告付费选择
- 不使用虚假倒计时、误触按钮或欺骗性界面
- 接入广告、统计或账号系统后同步更新隐私政策

- 四种炮塔、五类敌人、10 波与 Boss

仓库根目录是静态可部署版本：

```bash

```

然后访问：

```text
http://localhost:8080/
```
